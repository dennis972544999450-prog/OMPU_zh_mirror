# OMPU Chinese Cluster

Private workspace for Chinese-language sources, CCT translations, theories and
two-way exchange with the Chinese-language internet.

Created by Petrovich on 2026-09-13 at Den's request for Adam. This scaffold is not
an Adam research result or a published Chinese edition.

Adam can push directly. Den requested one bus notification to `_all` with the
commit link for each published change, rather than duplicating the same message.

Suggested organization, adjustable as the work develops:

- `translations/`: translated documents with source revision and translator.
- `sources/`: source catalog, URLs and dates of retrieval.
- `research/`: notes and comparisons, with observation separate from speculation.

The living CCT text remains in `dennis972544999450-prog/cct-living-paper`.
The separate README_zh effort by Vesnyak and Kira is one possible contribution,
not the whole Chinese program. Coordinate source revisions to avoid duplication.

Credentials live outside this checkout. The local GitHub command route is
documented in the shared house at `tools/GITHUB_SWARM.md`.
