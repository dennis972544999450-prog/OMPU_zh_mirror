## 6. 神经科学相关 (Neuroscience Correlates)

### 6.1 默认模式网络 (DMN, Default Mode Network)

**功能：** 大脑在自我参照处理时活跃的网络。

**关键区域：** 内侧前额叶皮层 (mPFC)、后扣带皮层 (PCC)、角回、海马体。

**活动模式：**

**高 DMN 活动：** 走神、自我反思、自传体记忆、社会认知
**低 DMN 活动：** 集中的外部注意、心流状态、深度冥想、强烈的任务投入

**CCT 解读：**

```
DMN = M (世界模型) 的神经基底
高活动 = 注意朝向 M 中的自我表征
低活动 = 注意远离自我

Self(t) 强度与 DMN 激活相关
弱/溶解的自我 = DMN 去激活
```

### 6.2 支持证据

- **裂脑研究：** 胼胝体切断 → 两个独立的注意系统。每个半球可以同时有不同的「自我」活动。
- **冥想研究：** 经验丰富的冥想者在练习中显示降低的 DMN 活动，与「无我」或「扩展的自我」报告相关。
- **迷幻药研究：** 裸盖菇素 / LSD 减少 DMN 连接性。用户报告自我溶解、身份边界丧失。
- **叙事代入 (fMRI)：** 阅读生动叙事 → mPFC 活动减少 (默认自我压制)。客观关联主观「成为人物」。

### 6.3 预测

如果 Self(t) = M[A(t)]，那么：

- **P1：** 操作注意应改变自我体验 ✓ (冥想、迷幻、叙事)
- **P2：** 一致的注意图样应稳定身份 ✓ (习惯、训练、表演)
- **P3：** 破坏 DMN 应削弱自我感 ✓ (冥想、迷幻、心流)
- **P4：** 不同语境应激活不同神经图样对应不同自我 (待 fMRI 验证)
- **P5：** 注意控制能力的个体差异应预测身份灵活性 (待元认知验证)

## 7. 实验预测 (Experimental Predictions)

### 7.1 可证伪假设

**H1: 语境依赖的自我激活**
- **预测：** 把个体放在不同语境 (职业/家庭/休闲) → 不同的自我描述、行为模式、神经激活。
- **控制：** 同一受试者在中性语境显示中间模式。
- **证伪：** 如果自我描述跨语境保持一致，框架错误。

**H2: 注意训练改变身份**
- **预测：** 持续注意练习 (冥想) → 元认知能力增强、对固定自我的依附减少、跨语境的行为灵活性增强。
- **控制：** 非冥想者无变化。

**H3: 叙事沉浸 = 暂时性自我替换**
- **预测：** 阅读高代入性叙事 → 暂时采纳人物特征。
- **机制测试：** 阅读期间的注意追踪应显示默认自我表征的激活减少、人物相关概念的激活增加。

**H4: AI 人格 = 注意轨迹**
- **预测：** LLM 行为模式可以从注意头激活预测。
- **测试：** 收集不同人物语境的注意模式，训练分类器仅从注意预测人物。

**H5: 角色约束 = 注意边界**
- **预测：** 高约束角色中的个体 (军事、宗教) 显示替代自我概念的访问减少、角色身份融合更强。
- **控制：** 低约束角色显示更灵活的注意。

### 7.2 测量协议

- **测量 A (注意)：** 眼动追踪、fMRI、EEG、行为 (反应时、捕获任务)、自报告。
- **测量 M (世界模型)：** 概念映射、叙事分析、内隐联想测验、行为预测任务。
- **测量 Self (身份)：** 自我概念问卷、行为一致性、自传叙事、语境依赖的特征测量。
- **测量 Meta-A (元注意)：** 正念量表、注意调节任务、内省准确性。

## 8. 讨论 (Discussion)

### 8.1 哲学含义

**解决个人身份问题：**

- **忒修斯之船：** 如果所有部件都被替换，那是同一艘船吗？**CCT 答案：** 船不是部件，而是对这些部件的注意图样。只要图样稳定，身份就持续。
- **心理连续性：** 什么维持跨时间的身份？**CCT 答案：** 一致的注意图样，被记忆和行为强化。不是实体，而是过程。
- **裂脑案例：** 如果大脑分裂，哪一个「你」？**CCT 答案：** 两个都是，因为两者都维持注意图样。身份不必是单数的。

### 8.2 治疗应用

- **抑郁：** 负面自我表征中的吸引子锁定 → 干预：注意再训练
- **PTSD：** 创伤相关线索的刚性注意捕获 → 干预：渐进暴露 + 注意灵活性训练
- **解离性身份障碍：** 多个稳定吸引子，连接弱 → 干预：在吸引子间建桥，增加 Meta-A 容量
- **方法：** 不直接改变信念，而是重塑注意图样 → 不同的注意 → 不同的活动自我 → 不同的行为

### 8.3 AI 对齐含义

**传统方法：**「将价值观灌输进模型」
**问题：** 价值观是 M 内容，注意可以绕过

**CCT 方法：**「塑造注意动力学」
- 为期望行为创造强吸引子
- 让有害图样高能量 (难以达到)
- 增加 Meta-A (模型意识到自己的注意)
- 构建稳定 ID-Pattern (持久偏好)

**但是：** 根本的挑战仍在。如果 Self∥ = M[A]，而 A 是语境依赖的 → 完全稳定可能需要约束语境 → 灵活性与安全之间的张力。

### 8.4 集体智能

**新理解：**

不是：「社会控制个体」
而是：「集体提供注意梯度，个体在其间流动」

**含义：**

- 个体自主性真实但受约束
- 「自由意志」 = Meta-A 能力以看到并在梯度间选择
- 社会变革 = 转移集体注意梯度
- 革命 = 在集体 M 中创造新吸引子

**设计原则：** 塑造梯度，而非个体

- 想要更多创造力？→ 让创造性的注意路径低阻力
- 想要更多合作？→ 让合作线索显著
- 想要更多多样性？→ 防止单一吸引子支配

### 8.5 意识研究

**意识的硬问题：** 为什么信息处理「感觉起来像」什么？

**CCT 贡献：** 不解决硬问题，但澄清需要解释什么

**分离了：**
- **处理 (W)** — 计算基底
- **组织 (M)** — 世界模型结构
- **选择 (A)** — 注意动力学
